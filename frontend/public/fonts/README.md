# Self-hosted web fonts

Latin-subset woff2 files served from this directory so the site makes no
third-party font requests. All are free and redistributable:

| File | Family | License |
|---|---|---|
| `press-start-2p-400.woff2` | Press Start 2P (CodeMan38) | [SIL OFL 1.1](https://openfontlicense.org) |
| `silkscreen-400.woff2`, `silkscreen-700.woff2` | Silkscreen (Jason Kottke) | [SIL OFL 1.1](https://openfontlicense.org) |
| `vt323-400.woff2` | VT323 (Peter Hull) | [SIL OFL 1.1](https://openfontlicense.org) |
| `big-shoulders-stencil-text-800.woff2` | Big Shoulders Stencil Text (Patric King) | [SIL OFL 1.1](https://openfontlicense.org) |
| `special-elite-400.woff2` | Special Elite (Astigmatic) | [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0) |

`@font-face` declarations live in `src/app/globals.css`.
